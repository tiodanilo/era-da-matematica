# Era da Matemática

Jogo de estratégia para o 6º e 7º ano. Capítulo I: Egito, depois da cheia do Nilo.
O aluno desenha os terrenos das famílias, descobre que o mesmo perímetro pode ter áreas diferentes
(e a mesma área, perímetros diferentes), colhe o trigo e enche o celeiro antes da chegada do escriba do faraó.
